# To-My-Hridipakhi (Premium Cinematic Interactive Birthday Experience)

এটি অর্ণবের পক্ষ থেকে হৃদিপাখির জন্মদিনের জন্য তৈরি একটি প্রিমিয়াম সিনেমাটিক এবং ইন্টারেক্টিভ ওয়েবসাইট। অ্যাপল এবং নেটফ্লিক্স দ্বারা অনুপ্রাণিত স্মুথ গ্লাস মরফিজম ইন্টারফেস দিয়ে সম্পূর্ণ বিশুদ্ধ বাংলায় এটি সাজানো হয়েছে।
